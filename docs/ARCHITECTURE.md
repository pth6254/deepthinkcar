# 구조 설명

## 전체 흐름 (20Hz)
```
조작 입력 ─┐
카메라 ────┼→ 안전 확인 → 모드별 조향·속도 → 급커브·난이도 속도 제한 → 서보·모터
           └→ 녹화 (data/)                                  └→ 웹 대시보드
```
`main.py`의 `Car.step()`이 한 주기를 처리합니다. 카메라, 녹화, 웹 영상은 별도 스레드입니다.

## 값의 약속
- 조향 `steer`: −1(왼쪽) ~ +1(오른쪽), ±`max_steer_deg`(60°)에 대응. 평소 자율주행은 `normal_steer_deg`(45°)로 제한
- 오차 `e`: −1 ~ +1, 양수면 차선 중심이 화면 오른쪽
- 모터 듀티 = `duty_min` + 스로틀 × (`duty_max` − `duty_min`)

## OpenCV 차선 인식 (`autopilot/lane_detect.py`)
HSV 색 마스크 → 블러 → Canny → ROI → HoughLinesP → 기울기로 좌우 분류 → 주시 행에서 중심 계산.
한쪽만 보이면 학습된 차선 폭으로 중심을 추정하고, 좌우는 직전 위치로 구분합니다. 빨강처럼 색상(H)이 0을 넘나드는 범위도 지원합니다.

## AI 주행 (`autopilot/cnn_pilot.py`)
NVIDIA PilotNet(DAVE-2) 구조의 사전 학습 모델을 자체 트랙 데이터로 파인튜닝합니다.
- 입력: 화면 아래 절반 → YUV → 블러 → 200×66. 출력: 조향 각도 하나(90° = 직진)
- 파인튜닝: 합성곱층은 고정하고 뒤쪽 층만 학습. 정답 조향은 OpenCV가 붙임 (`--labels human`으로 사람 조향 선택 가능)
- 주행 중 OpenCV가 차선을 감시하고, AI가 크게 덜 꺾을 때 보정

정답을 OpenCV가 붙이므로 **OpenCV가 틀리는 장면은 AI도 틀리게 배웁니다.**

## 급커브 대응
| 기능 | 조건 | 동작 |
|---|---|---|
| 모서리 감지 (`sharp_corner.py`) | 안쪽 테이프가 뾰족하게 꺾임 | 멈칫 → 끊어 전진 → 최대 조향 |
| U턴 연결 | 모서리 직후 반대편 테이프 끝이 보임 | 핸들이 돌 때까지 정지 후 반대로 최대 조향 |
| 바깥 테이프 추적 | 한 줄이 앞을 가로지름 | 조향을 풀지 않음 |
| 한쪽 차선 보강 | 한쪽만 보이고 오차 0.6 이상 | 오차에 비례해 60°까지 |
| AI 보정 | 오차 0.8 이상인데 덜 꺾음 | OpenCV만큼 꺾음 |

끄는 설정: `sharp_turn`(앞의 세 가지), `single_lane_boost`, `assist_error`

## 속도 결정
1. 커브 정도에 따라 직선 속도 ~ 커브 속도
2. 난이도(`difficulty.py`): 오차, 한쪽 차선, 오차 증가, AI 불일치, 조향 한계 중 최댓값
3. 난이도 0.7 이상이나 급커브에서는 **끊어 전진**. 더 낮은 출력에서는 모터가 멈출 수 있어 전진과 쉼을 반복

감속은 즉시, 복귀는 쉬운 상태가 0.5초 이어진 뒤 천천히 합니다.

## 학습 데이터
`data/<날짜_시간>/images/*.jpg`와 `log.csv`(시각, 이미지, 조향, 스로틀, 모드, 최대 조향각).
AI 주행의 조향은 정답으로 쓰지 않습니다. 녹화는 약 2초마다 디스크에 확정합니다.

## 새 기능을 넣을 때
녹화를 다시 재생해 **잘 달리던 구간의 조향이 달라지지 않는지** 이전 버전과 비교한 뒤 실차에서 확인합니다. 재생은 차의 위치가 바뀌는 효과를 반영하지 못하므로 실차 확인을 대신하지 못합니다.
